# SANITIZED SAMPLE DATA — NOT THE FULL SOURCE DATASET

This directory contains a small, anonymized subset of the transformed church data.

**Purpose**: To allow recruiters and reviewers to inspect the output schema and relational structure of the ETL pipeline without exposing the full dataset or any potentially sensitive information.

*   `churches_sample.csv` (5 representative rows)
*   `services_sample.csv` (7 representative service rows)

The actual pipeline extracts 101 records into the `.gitignore`'d `processed/` directory.
